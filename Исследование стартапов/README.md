# 🚀 Исследование стартапов

📄 Анализ исторических данных о финансировании стартапов с целью выявить закономерности и оценить перспективы инвестиций в венчурный сектор. В ходе проекта данные загружены и предобработаны, созданы новые признаки, выявлены выбросы, ограничен период анализа. На основе анализа сформулированы выводы и рекомендации по оптимальным направлениям и типам инвестирования.

---
🛠 **Инструменты:** python, pandas, numpy, matplotlib, seaborn

---
🧠 **Навыки:** обработка данных, приведение типов данных, дубликаты, пропуски, инжиниринг признаков, категоризация, сегментация рынка, анализ выбросов, группировка и сортировка, агрегация данных, визуализация данных, анализ динамики

---
**Статус проекта:** Завершен ✅
